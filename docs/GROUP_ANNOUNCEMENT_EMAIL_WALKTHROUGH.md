Dummy SMTP acceptance is saved on the server for that exact revision. Client request fields cannot approve an attachment or forge a receipt. An approved client PDF plus a same-version successful dummy, an enabled worker, eligible recipients and no contact issues enable the manual bulk confirmation. The confirmation asks staff to review the dummy in their inbox; SMTP acceptance by itself does not certify its appearance or inbox arrival.

**Send to All Assigned Registrants** creates one deterministic campaign for that event/content revision and returns HTTP 202 after an atomic snapshot commit. It does not send client mail in the HTTP request. The saved recipient list is immutable. A repeat click, another browser or retry after a lost response returns that same campaign; it cannot start the same version over again. A different email version cannot start while the latest campaign still has unfinished recipients. Every contact issue blocks a new campaign instead of silently skipping clients.

The background worker scans saved runnable campaigns. It sends sequentially with a durable minimum one-second gap, transactionally claiming a three-minute lease for each recipient. It records SMTP acceptance, explicit rejection or uncertainty, plus a stable message ID and safe review reason. These are transport outcomes, not proof of reading or inbox delivery. Failed/uncertain deliveries are never automatically retried. The later 21 October individual resend action requires an explicit row confirmation and provider verification for uncertain deliveries; see the individual resend section above.

A crash after a send begins may leave its result unknown. When the lease expires, another worker marks that recipient uncertain and advances to pending recipients **without resending**. Fenced attempt IDs prevent a late old worker from overwriting recovery or advancing the cursor twice. Pending work survives backend restart. Missing/unapproved/changed content pauses the campaign; restore the exact approved version and explicitly resume its saved recipient list. Never overwrite a snapshot or manufacture a new version just to retry uncertain sends.
